## 2026-09-10T18:20:00+10:00 — Iteration: continuous location publishing

**Author of prompt:** Ethan
**AI model:** Claude Sonnet 5 via Claude Code

**Prompt / request:**

Next iteration: publish the current user's location continuously so other
players' pins actually move, instead of the one-shot write per map visit.
Fold in the cold-start `permission-denied` retry fix noted earlier.

**What was done:**

- [`useForegroundLocation.ts`](../../src/features/map/hooks/useForegroundLocation.ts):
  after the initial fix, starts a `watchPositionAsync` subscription
  (`distanceInterval` = `LOCATION_WATCH_DISTANCE_M`, 10 m) and pushes each update
  into `locationState`. Subscription is torn down on unmount and on retry.
- [`usePresencePublisher.ts`](../../src/features/map/hooks/usePresencePublisher.ts):
  rewritten around a self-scheduling `publish()` —
  - keyed on the **coarsened** cell, so GPS jitter inside one ~110 m cell does
    not cause writes;
  - **heartbeat**: re-publishes every `PRESENCE_HEARTBEAT_MS` (60 s) to keep
    `lastSeen` fresh;
  - **retry with backoff**: 2s / 4s / 8s, staying in `publishing` until the
    retries are exhausted, only then `error` (fixes the cold-start
    auth-token/connection race);
  - a second effect deletes the presence doc on unmount / logout (best effort —
    see follow-up).
- [`presenceRepository.ts`](../../src/features/map/services/presenceRepository.ts):
  added `removePresence(uid)` (a `deleteDoc` — rules forbid writing
  `isVisible: false`).
- [`useNearbyPlayers.ts`](../../src/features/map/hooks/useNearbyPlayers.ts):
  re-checks staleness on a timer, not only when a snapshot arrives, so silent
  players drop off.
- [`map.constants.ts`](../../src/features/map/constants/map.constants.ts):
  `LOCATION_WATCH_DISTANCE_M`, `PRESENCE_HEARTBEAT_MS`,
  `PRESENCE_MAX_PUBLISH_RETRIES`, `PRESENCE_RETRY_BASE_DELAY_MS`;
  `PRESENCE_STALE_AFTER_MS` tightened from 10 min to 3 × heartbeat (3 min).
- [`tsconfig.json`](../../tsconfig.json): `exclude` `apm_modules` / `node_modules`
  — `apm install` pulled skill scripts with Bun/Node globals that were breaking
  `tsc`.

**Follow-ups:**

- Logout deletes presence only best-effort: `signOut` runs first, so the delete
  usually hits the rules unauthenticated and fails; the doc then ages out via
  the 3 min staleness window. A clean fix removes presence before `signOut` in
  `App.tsx`.
- No background-location handling; presence only updates while the map screen is
  foregrounded.
- Manual privacy/invisible toggle (task 2.4) still outstanding — `removePresence`
  is the building block.

**Verification:** `npx tsc --noEmit` clean; `npx prettier --check` clean. Not yet
run against two live devices.
