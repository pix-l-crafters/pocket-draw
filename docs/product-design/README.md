# Pocket Draw Product Design

This document serves as a human written specification for the game "Pocket Draw".

This game is a group assignment for Mobile Computing Systems Programming subject where we have to make a mobile app which utilises multiple sensors.

## Premise

The main premise of Pocket Draw is a co-located 2 player game where each player uses their phone as a gun to shoot at each other.

Fastest to fire & accurate to aim wins.
