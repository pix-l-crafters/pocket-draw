# Leaderboards

Once a match is over, player's statistics are saved against their profile.

These statistics will be stored of player:

1. Number of wins
2. Number of losses
3. Number of draws
4. Average Reaction time

In the leaderboard section, the UI will show rankings based on their wins/losses ratio.

Additionally they can see wins-only/loss-only/draws-only/average-reaction-time-only leaderboards.
