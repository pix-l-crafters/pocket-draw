# Leaderboards

Once a match is over, player's statistics are saved against their profile.

These statistics will be stored of player in the database:

1. Number of wins
2. Number of losses
3. Number of draws
4. ELO rating (low priority)
5. Average Reaction time (do only when we have time)

In the leaderboard section, the UI will show rankings based on their:

1. wins/losses ratio.
2. wins-only
3. loss-only
4. draws-only
5. ELO Rating (low priority)
6. average-reaction-time-only (do only when we have time)
